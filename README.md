# 給朋友的感謝網頁｜第一版

這是一個純 HTML / CSS / JavaScript 的靜態網頁原型，不需要安裝套件。

## 開啟方式
直接雙擊 `index.html` 即可預覽。

## 檔案
- `index.html`：內容與結構
- `style.css`：版面、配色、動畫
- `script.js`：滑入動畫、照片翻卡、開信、最後一句互動

## 你之後最需要替換的內容

### 1. 照片
目前使用 `PHOTO 01` 等灰色示意區塊。
之後可以改成：
```html
<img src="images/photo01.jpg" alt="">
```

### 2. 文字
目前文字是示意稿，可直接在 `index.html` 裡修改。

### 3. 背景音樂
目前右上角音樂按鈕只是互動示意。
若要加入音樂，可以新增：
```html
<audio id="bgm" src="music.mp3" loop></audio>
```
再由 JavaScript 控制播放／暫停。

## 目前已完成的互動
- 捲動進場動畫
- 回憶時間軸
- 照片翻卡
- 感謝文字段落
- 開信動畫
- 最後一句揭曉
- 手機版響應式排版
